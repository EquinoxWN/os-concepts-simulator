## Analyze

- **No algorithm wins every column.** SRTF has the lowest mean waiting time on every trace (the
  property test checks this on 200 more), but on random-2 its fairness (0.332) is below SJF's
  (0.351): it finishes short jobs early and lets long ones absorb the delay.
- **Round robin buys response time with everything else.** On random-2 it answers first in 135
  ticks on average against 663 for SRTF, has the best fairness (0.862), and the worst mean
  turnaround (1,622) with 2,123 dispatches against 238.
- **Arrival times change the ranking.** With every job present at 0, SJF equals SRTF; when the
  short jobs arrive while the long one runs (ostep-late-short), SJF cannot preempt and is as bad
  as FCFS (103.33), while SRTF stays at 50.
- **Priority scheduling is only as good as the priorities.** With random priorities (random-2) its
  maximum slowdown (3,603) is the worst of all; on interactive-mix, where interactive jobs have the
  best priorities, it is close to SJF.
- **Max slowdown exposes starvation** that means hide: on random-2 one job under FCFS spent 1,551
  times its own run time in the system.

Defects found and their root causes:

| # | Defect | Root cause | Evidence |
|---|---|---|---|
| 1 | The static server's resolver accepted a path with a NUL byte (`/web/index.html%00.js`) | Decoding happened before the check, and no rule refused control characters; the file system call would have failed, so it was not exploitable, but it was not refused either | `resolveStatic never leaves the root` test, first run |
| 2 | Test expected `/../package.json` to be refused | URL parsing already clamps `..` at the root, so the path stays inside; the test's expectation was wrong, not the code | same test |
| 3 | Two tests assumed a fixed first event | Start order follows the documented tie-break rules | first run |
| 4 | `pip-audit` reported 4 advisories in the virtual environment's pip 26.1.1 | The venv kept the pip bundled with Python 3.14.5 | first full check |
| 5 | `mypy --strict` rejected arithmetic on per-job values | A dict built without a type annotation was inferred as `dict[str, object]` | first type check |

| Control | Holds |
|---|---|
| `reference.test.ts` and `expected --check` in CI | Engine and reference cannot drift apart, and expected files cannot go stale |
| Textbook tests in both languages | Both implementations stay pinned to published results |
| 200-workload property test | Scheduling invariants and SRTF optimality on new random traces every push |
| `parseTrace` limits (2,000 jobs, burst 10,000, total 1,000,000) and the worker's error replies | A bad or huge trace cannot hang or crash the page |
